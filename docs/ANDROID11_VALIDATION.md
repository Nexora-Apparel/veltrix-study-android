# Android 11 acceptance checklist

- Install and launch the native APK on Android 11.
- Confirm offline import of 196 sourced question records.
- Prepare the 180-question mixed-year paper (60/40/40/40).
- Verify Begin Exam starts the persisted 120-minute timer.
- Verify answer persistence across force-stop/reopen, submission marking, automatic expiry and historical corrections.
- Verify focus sessions are recorded once and progress survives restart.
- Verify notes, timetable completion and reminders.

Cloud sync remains gated: the source project is personal/private and the Android app does not yet have a native authenticated session. Do not weaken project privacy or embed administrator credentials.
